# PixelTank 坦克大战

一个基于 Web 的经典坦克大战游戏，采用 **服务器-客户端（Server-Client）** 架构，支持双人网络联机对战。

## 功能特性

- 🎮 **经典坦克大战玩法**：移动、射击、躲避敌人，守护基地
- 🌐 **双人网络联机**：通过房间码创建/加入房间，支持双人协同作战
- 🗺️ **多关卡**：内置 10 个关卡地图，难度逐级递增
- 🤖 **多种敌人类型**：轻型、普通、重型坦克，属性各异
- ⚡ **丰富的道具系统**：速度、伤害、弹速、回复、冷却缩减等 10 种增益道具
- 🛠️ **地图编辑器**：可视化绘制地形、测试并保存自定义关卡
- 🖥️ **服务器权威**：游戏逻辑完全在服务器端运行，客户端仅负责输入与渲染，防作弊

## 技术架构

```
┌─────────────┐    WebSocket     ┌──────────────────────────┐
│  浏览器客户端  │ ◄──────────────► │         Node.js 服务器     │
│  index.html  │  输入/状态同步    │  server/server.js          │
│  game.js     │                  │  房间管理 + 状态广播        │
│  network.js  │                  │  server/game-engine.js     │
└─────────────┘                  │  游戏逻辑（60 FPS 权威计算） │
                                 └──────────────────────────┘
```

- **客户端**：只负责收集键盘输入、渲染服务器同步过来的游戏状态，不包含本地游戏逻辑
- **服务器端**：为每个房间独立运行一个 `GameEngine` 实例，60 FPS tick 循环，每 2 帧同步一次游戏状态到所有客户端

## 目录结构

```
PixelTank/
├── index.html        # 游戏主页面
├── game.js           # 客户端渲染与输入处理
├── network.js        # WebSocket 客户端（NetworkManager）
├── editor.html       # 地图编辑器页面
├── style.css         # 页面样式
├── run.sh            # 一键启动脚本
└── server/
    ├── server.js         # WebSocket 服务器（房间管理、状态同步）
    ├── game-engine.js    # 服务器端游戏引擎（Tank/Bullet/PowerUp/AI）
    ├── constants.js      # 共享常量（缩放比例、瓦片、方向枚举等）
    ├── game-config.json  # 游戏配置（玩家/敌人/道具/关卡）
    ├── package.json      # 服务器依赖（ws）
    └── maps/             # 10 个关卡地图 JSON（level1 ~ level10）
```

## 环境要求

- Node.js（含 npm）
- Python 3（用于启动静态文件服务器）

## 快速开始

### 方式一：使用启动脚本

```bash
./run.sh
```

脚本会自动安装服务器依赖并同时启动 WebSocket 服务器和 HTTP 服务器，浏览器访问 `http://<主机IP>:8000` 即可。

### 方式二：手动启动

```bash
# 1. 安装服务器依赖
cd server && npm install && cd ..

# 2. 启动 WebSocket 服务器
node server/server.js &

# 3. 启动 HTTP 静态服务器
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000`。

> 注：默认 WebSocket 地址为 `ws://localhost:8080`，可通过全局变量 `window.WS_HOST` / `window.WS_PORT` 覆盖。

## 联机对战

1. 在游戏主界面「创建房间」生成 4 位房间码
2. 另一名玩家在「输入房间码」处加入房间
3. 两人都加入后，由主机（创建者）开始游戏

- 房间满 2 人后无法再加入
- 任一玩家可暂停/继续游戏
- 对方断线后游戏自动切换为单人模式

## 地图编辑器

`editor.html` 提供可视化地图编辑功能：

- 支持绘制空地、砖块、钢铁、水域、草地、基地 6 种地形
- 支持 1x1 ~ 4x4 画笔大小，左键绘制、右键擦除、拖动连续绘制
- 可设置地图名称、描述、敌人数量
- 保存/加载/清空地图，并可在编辑器内直接测试（支持单人/双人）

## 游戏配置

所有数值均通过 `server/game-config.json` 配置（内部数值缩放 10000 倍）：

- **玩家**：速度、生命、弹速、伤害、射速冷却等
- **敌人**：轻型（light）/ 普通（normal）/ 重型（heavy）三档属性
- **道具**：百分比与固定值两种加成方式
- **关卡**：地图文件索引，可自由增删关卡

## 技术说明

- 内部坐标数值统一放大 10000 倍（`SCALE`），渲染时除以该值，避免浮点精度问题
- 地图为 26×26 瓦片（每瓦片 32px），画布 832×832
- 服务器每 30 秒清理一次无玩家的空房间
